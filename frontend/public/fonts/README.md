# Шрифты для вжигания текста

Четыре семейства с кириллицей и казахскими глифами (Ұ, ң, і, ә, ө, ғ, қ, һ),
проверено рендером. Каждое — вариативное начертание одним файлом, поэтому
жирность задаётся тегом, а не отдельным файлом на каждый вес.

## Почему они лежат в репозитории, а не ставятся в систему

libass, когда запрошенного шрифта нет, **молча берёт другой**. Не предупреждение,
не ошибка — просто чужая типографика в готовом ролике клиента и пустой лог.

Это не теория. Код просил Montserrat, в Docker-образе он стоял, а воркер
запускался на макбуке, где его не было, — и libass подставлял Verdana. Все
ролики того периода отрендерены не тем шрифтом, и заметить это можно было
только глазами.

Отсюда правило: шрифт должен ехать вместе с кодом. `ffmpeg.ts` передаёт фильтру
`ass` параметр `fontsdir`, указывающий сюда, и libass берёт шрифты отсюда, а не
из системы. Один и тот же результат на макбуке, в Docker и где угодно ещё —
независимо от того, что установлено на машине.

Следствие: добавить шрифт в список = положить файл сюда. Установка в систему
или пакет в `Dockerfile` для этого не нужны.

## Лицензия

Все четыре под SIL Open Font License 1.1, которая прямо разрешает
распространение вместе с программой. Текст лицензии лежит рядом с каждым
файлом (`*.OFL.txt`) — OFL требует прикладывать его к копиям.

Источник: [Google Fonts](https://github.com/google/fonts).

| Файл | Семейство | Характер |
|---|---|---|
| `Montserrat.ttf` | Montserrat | Геометрический гротеск, нейтральный |
| `Oswald.ttf` | Oswald | Узкий — много слов в строку |
| `Unbounded.ttf` | Unbounded | Широкий, заметный |
| `PlayfairDisplay.ttf` | Playfair Display | Антиква с засечками |

Имя семейства (второй столбец) — это то, что попадает в `Fontname` внутри
`.ass`, и оно не всегда совпадает с именем файла: `PlayfairDisplay.ttf`
называется `Playfair Display`, с пробелом.
